## 口径说明

- 小时桶：存 UTC 整点，显示层用设备本地时区格式化；旧 v2 本地小时桶在读取时按当前 UTC 偏移校正一次。
- 脚本命中 action：统一记 `rewrite`，由 `sourceType=script` 区分；这是归因摘要口径，不代表实际 HTTP 语义。
- 最近命中：`ring` 只保留字段白名单；关闭摘要后内存可读、磁盘不再写。
- 空态：未启动 → VPN 引导；已启动、窗口 0、ring 空 → 空态；已启动、窗口 0、ring 有 → 成功态 0 / 拦截率“—”。
