# 南门 DNS · 功能清单与应用壳设计

最低系统为 Android 12（API 31），应用基线为 2.0（69）、内核 1.11.5。以下盘点依据本次源码中的页面、路由、解析器和统计模型。设备端证书信任、代理可达与过滤效果须在目标设备上验证。

## 功能地图

| 归属 | 1.34.0 已有能力 | 新壳入口 |
|---|---|---|
| 连接与系统入口 | Android VPN 授权、启动和停止、服务重载、自动连接、前台速率通知、快捷磁贴、通知切换节点、首次引导 | 首页主开关；设置管理自动连接与引导 |
| DNS 去广告 | UDP / DoT / DoH、Bootstrap、自定义 DoH 头、备用上游、异常结果复核、缓存、本地域名与订阅过滤、拦截响应、AAAA 控制、DNS 日志 | 策略 → 规则 → 当前配置 |
| 分流与隧道 | 规则、全局代理、仅 DNS 模式；TCP/UDP、Fake-IP、域名嗅探、国内直连、国内 IP 库、最终策略、域名/IP/端口规则、规则开关、搜索与匹配测试 | 首页切模式；策略编辑与测试 |
| 节点与订阅 | SOCKS5、SS、Trojan、VLESS 的已有实现；节点链接、Base64、Clash、订阅 URL、相机扫码与手动粘贴；订阅用量与到期、分组折叠、搜索、排序、测速、自动选快、切换、批量删除与导出 | 首页 → 服务器；通知直达；数据页保留导入导出 |
| 配置文件 | 新建、切换、粘贴导入、远端拉取、恢复默认、删除、旧配置迁移、规则源自动更新 | 策略 → 规则 → 配置文件 |
| 规则模块 | URL 导入前预览、重复项计数、确认写入、同步启用模块、启停、删除、解析规则数量、忽略项和错误；支持 JSON 以及部分 sgmodule 风格的域名、分流和重写段 | 策略 → 模块；配置详情保留原有入口 |
| HTTPS 高级功能 | CA 状态与导出、系统信任状态、域名和跳过列表、HTTP/1.1 与 HTTP/2 的有限重写、gRPC 请求拒绝、运行计数；私人 DNS 状态提示与控制 | 设置 → 高级功能；数据页查看计数 |
| 数据与诊断 | 会话查询与拦截、上下行速率与曲线、连接、缓存、延迟分布、回退与 MITM 计数；运行/DNS 日志、筛选搜索、展开复制、滚动控制、诊断报告导出 | 数据；首页展示两项会话摘要 |
| 外观与辅助 | 系统/浅色/深色、触感反馈、大屏限宽、日志自动清理、引导回看 | 设置、关于与公共壳 |

模块的 App 标签用于分组。脚本和 PROCESS-NAME 属于现有解析器的能力边界。解析到重写条目、设备信任证书、运行时命中是三个独立事实。gRPC 请求拒绝与通用 protobuf 正文编辑也应分别标注。

## 导航与视觉

底栏为「首页、策略、数据、设置」。节点、扫码、配置详情、运行日志、DNS 日志与证书管理保留二级页和系统返回。策略页使用「规则｜模块」分段；规则区首先打开当前配置，也保留所有旧配置文件操作。模块区挂载同一份模块列表与数据源。切换底栏时恢复导航状态；系统通知仍可直接打开节点页。

首页优先呈现连接状态和本次统计，随后显示分流模式、当前配置和服务器。VPN 建立且本次查询为零时显示等待状态。收到查询仅能证明 DNS 流量已进入，过滤开关和实际拦截次数分别显示。启动与停止状态优先于历史计数。数据页承载明细，首页避免重复堆放图表。

页面用雾白和深灰两套底色，松绿标记主选择，正文随主题变换。悬浮 Dock 四项等宽，系统导航区上方留白，大屏限宽居中。触控目标至少 48dp，图标与文字共同表达选中态。页面内容可滚入 Dock 下方。Dock 使用 Android 12 起支持的硬件模糊采样底下的页面，叠加半透明底色；图标与文字独立绘制。列表末端按实际底栏高度留白。短线随选中项移动，页面切换短暂淡入；待机时导航没有循环动效。

| 阶段 | 交付 | 验收路径 |
|---|---|---|
| 第一批 · 本次施工 | 四项 Dock、策略双分区、现有模块入口、首页真实状态与查询统计、公共顶栏 | 分别打开四页；从规则进入当前配置后返回；切到模块再来回切页；关闭过滤也能接收 DNS；无节点直连、零查询、启动与停止状态均能区分 |

| 第三批 | 本地文件导入复用已有 URL 预览、逐模块能力明细、日志命中来源 | 导入含支持与未支持段的样例；确认后才写入配置；能从日志回到来源模块。规则来源需从解析、合并到日志全程保留 |
