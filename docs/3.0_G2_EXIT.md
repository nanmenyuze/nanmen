## 3. S2 无损迁移

- `ProfileMigration` 逐份解析 `files/configs/*.conf`；缺 `groupSelections` 时复制旧设备全局选择，模型版本升 4。
- 先 dry-run 校验全部 Profile；任一硬错误则该份不写。apply 前备份到 `files/configs/profile-migration-backup/<name>`，原子写入并记录 `.profile-migration-v4.json`；rollback 只恢复清单内文件。
- `AppContainer` 在 `ConfigFileStore.migrateLegacy` 后执行；迁移有改动时重新加载 active `.conf`，避免 DataStore 继续使用旧快照。
- 证据：`ProfileModelTest > profile migration dry-run applies backup and rolls back`；`ProfileMigration.semanticEqual` 只忽略 `version/groupSelections/configUnknown`。
- 旧 v2 小时桶：`hits::tests::v2_local_buckets_are_upgraded_once_and_rewritten_as_v3`，读入按当前偏移校正后立即写回 v3，二次加载不再减偏移；改时区不会二次校错。

## 6. S6 C 壳

- `AppConfig/GeneralConfig` 增加 `ssidTriggerEnabled/ssidTriggerNames/ssidLocationOptIn`，默认关；Manifest 增加 Wi-Fi/定位权限。
- `SsidTrigger` 先判开关，再判本地 opt-in，再判权限；Android 13+ 请求 `NEARBY_WIFI_DEVICES`（neverForLocation）并保留 `ACCESS_FINE_LOCATION`（平台仍将当前 SSID 归为 location-sensitive）；只读当前 SSID，不采集、不存、不上报位置。`matches` 对空 SSID、`<unknown ssid>`、空名单返回 false。
- `permissionName(sdk)` 显式覆盖 33/32 分支，`requiredPermissions(sdk)` 在 33+ 返回 NEARBY + FINE，消除原死分支。
- `ModuleGeneral` 把 `[General]` 的 `skip-proxy/bypass` 合入 MITM 跳过域名，`ssid-trigger` 合入 SSID 名单，`proxy-test-url/test-timeout/force-close-connections` 存入 `generalEffects`。
- `ConfigStore.effectiveSsidTriggers` 合并 Profile 名单与模块名单；`[General]` 其余键保留审计，不静默当已生效。
- 证据：`ProfileModelTest > module general maps shell keys without touching kernel`、`ssid matching rejects blank unknown and empty list`、`ssid permission follows sdk and keeps location for ssid`；`ModuleParser` 解析用例。
